## Platform

web

## Stack

TanStack Start 1.0 React (Vite 8), TanStack Router 1.170.46, Better Auth, Tailwind 4, TypeScript, pnpm. Deploy: Cloudflare Workers (`wrangler deploy`, Nitro preset `cloudflare`). Secrets: `SITE_USER`, `SITE_PASS`, `SESSION_SECRET`, `GH_TOKEN`.

## Users

[inferred] Primary user is the repo owner (Stefy), studying iOS/SwiftUI personally. Situation: solo developer/learner at a desktop browser. Job: watch course videos, mark lessons complete, take per-lesson notes, track resume position.

## Product Purpose

Personal video-course platform replacing Sean Allen's Teachable school (closing 24 Nov 2026). Plays downloaded videos (H.264/AV1) from a private GitHub repo (`orchard`), tracks progress and notes in browser localStorage (`hub:*` keys), requires login (cookie-based session + Basic Auth fallback). Zero cost, personal use only.

## Positioning

All media lives in one private repo (`orchard`) served through an authenticated Worker route — no public bucket, no HMAC URLs, no second project. Auth is a single signed cookie across app and media on one domain.

## Operating Context

- Dev: `pnpm dev` (Vite + Nitro on Node), media read from `APPLECORE_MEDIA_DIR` (default `media`, outside `public/`)
- Prod: Cloudflare Workers, media fetched from GitHub `orchard` with `GH_TOKEN`
- Catalog: `src/data/catalog.json` regenerated by `scripts/build-catalog.mjs` (merge per module)
- localStorage keys: `hub:pos:<id>`, `hub:done:<id>`, `hub:note:<id>`
- Routes: `/` (landing/hub), `/better-auth`, `/c/$courseId`, `/c/$courseId/l/$lessonId`, `/media/$`, `/api/auth/$`

## Capabilities and Constraints

- Video < 100 MB each (GitHub limit); repo total ~1.5 GB, target ≤ ~5 GB
- Media > 50 MB stored as split 50 MB parts (`_split/`), reassembled on demand by the media route
- AV1 encode only for files > 100 MiB (720p CRF34 preset10 g240 audio copy faststart)
- Personal use license: media must not be exposed publicly (no YouTube/R2 public)
- Basic Auth remains as fallback for external clients (download tools)

## Product Principles

1. One source of truth for media (private `orchard` repo), never duplicated storage
2. Single signed cookie controls both app and media access on one domain
3. Personal use only — never expose course material publicly
4. TanStack Start + Router, never Next.js / App Router
